# Material für die AKKI-Website

## Im Repo
Der Ordner `hackathon-website/` enthält die bestehende Hackathon-Seite (https://akki-hackathon-2026.vercel.app/) als Vorlage für Aufbau und Design.

| Datei | Inhalt |
|---|---|
| `hackathon-website/index.html` | Seitengerüst, enthält auch das AKKI-Zeichen als eingebettete Grafik |
| `hackathon-website/styles/main.css` | Farben, Schriften, Abstände |
| `hackathon-website/scripts/content.js` | Alle Texte der Seite auf Deutsch und Englisch, auch die neun Use Cases |
| `hackathon-website/scripts/main.js` | Sprachumschaltung und Menü |
| `hackathon-website/assets/kesselhaus.jpg` | Foto des Veranstaltungsorts |
| `hackathon-website/assets/ukb-logo.svg` | Logo BG Klinikum Unfallkrankenhaus Berlin |
| `hackathon-website/assets/helliwood-logo.png` | Logo Helliwood media & education |

Das Minispiel der Seite (`minigame.js`) fehlt absichtlich, es hängt an einem externen Dienst.

## Design in Kürze
| Element | Wert |
|---|---|
| Hintergrund | `#0D2740` (dunkelblau), zweite Fläche `#14202B` |
| Akzent | `#45E9DA` (türkis), `#63B4E6` (hellblau) |
| Text | `#EAF3F7`, zurückhaltend `#8A99A2` |
| Überschriften | Schrift „Archivo“ |
| Fließtext | Schrift „Manrope“ |
| Ecken | 14 Pixel Radius |

## Rechte
- Die Logos gehören dem BG Klinikum Unfallkrankenhaus Berlin und Helliwood. Auf einer neuen Seite nur mit deren Zustimmung verwenden.
- Beim Foto des Kesselhauses vor einer Wiederverwendung die Bildrechte klären.
- Texte und Design der Hackathon-Seite stammen vom Arbeitskreis.
